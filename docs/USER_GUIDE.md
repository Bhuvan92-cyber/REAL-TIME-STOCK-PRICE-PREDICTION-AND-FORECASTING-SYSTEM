# User guide

1. Configure Supabase and the public frontend variables.
2. Register and confirm an account, then sign in.
3. Use Market and Technical pages for provider-backed quotes and indicators.
4. Use Forecasting only when a registered model artifact is available.
5. Create watchlists, virtual portfolios, alerts, and inspect prediction
   history from authenticated pages.
6. Review subscription limits on Pricing/Subscription pages. Billing is
   intentionally disabled; no upgrade or payment success is simulated.

Market data may be delayed or unavailable. Forecasts and risk analytics are
informational estimates, not financial advice or trading instructions.
