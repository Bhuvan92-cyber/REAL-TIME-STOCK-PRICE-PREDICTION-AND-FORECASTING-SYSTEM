# Operations

Use `/health` for a public liveness check. Application failures are returned
as safe messages and should be correlated with server logs. The scheduled
alert workflow records execution results through the protected internal
endpoint. Provider data may be delayed or unavailable; the application must
not replace missing values with fabricated prices.

Monitor API cold starts, Supabase errors, provider quotas, forecast latency,
and notification failures. Keep billing disabled until webhook and
reconciliation controls are independently reviewed.
